# QuickWash Full Stack Project

## Run backend
```bash
cd backend
npm install
npm start
```
Backend runs on: `http://localhost:5000`

## Run frontend
Open the files inside the `frontend` folder using Live Server in VS Code, or any static server.
Recommended start page: `index.html`

## Flow
1. Signup
2. Login
3. Add services in `product.html`
4. Checkout in `payment.html`
5. Track orders in `orderTracking.html`

## Important
- `orderTracking.html` automatically uses the logged-in user name and fetches only that user's orders.
- The tracking screen shows location text, progress, map link, and handover-ready notification.
